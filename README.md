# Local AI Agent - Hugging Face Agents Course

Final project for the Hugging Face Agents Course. The agent answers evaluation questions using locally hosted models and tools.

Since the evaluation questions require very short answers, the agent's system prompt instructs it to respond with a single word or a short phrase.

## Technologies used

- Ollama for hosting the models locally
- LlamaIndex for creating the agent and tools
- RAG for retrieving relevant content from long web pages. Given a web page and a query generated by the agent based on the information it needs, the tool retrieves the relevant sections rather than passing the entire page to the agent
- Python as the programming language

## Code structure

- `agent/agent.py`: The agent configuration and execution
- `tools/`: The tools used by the agent
- `models/models_factory.py`: The models (LLM and embedding) used
- `try_challenge/`: Helper functions for running the agent on a single question
- `execute_questions.ipynb`: Notebook for running the evaluation questions and collecting answers

## Execution

This Space contains the source code for review, not a hosted inference demo. To run the agent, you need to clone the repository and execute it in your local environment.

## Requirements

- Python 3.12 
- A Python virtual environment with the dependencies from `requirements.txt` installed
- A GPU that can run the models
- Ollama installed and running with the required models (`gpt-oss:20b` and `nomic-embed-text`)
- A `files/` folder with the files of the questions with their expected filenames and a `questions/` folder with the questions in the JSON structure expected by the code. These folders are not included

## Running the agent

Once the environment is configured and the files are in place, run the `execute_questions.ipynb` notebook using your Python environment as the notebook kernel. This notebook generates answers, stores them in a dictionary, and prints that dictionary in its final cell.
